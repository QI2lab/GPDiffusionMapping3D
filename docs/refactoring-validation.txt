FILE INPUT AND CLI IMPLEMENTED; FINAL SUITES PENDING

read_track_table selects pandas CSV or PyArrow Parquet by suffix. Column mapping
and physical preparation are shared in prepare_table_tracks / prepare_tracks.
CSV particle identities use strings; Parquet identities retain their native
values. No identity is cast through float64. XY or ZYX positions are converted
to nanometers before preparing within-particle displacements. Numeric seconds
are sorted within each particle and actual positive elapsed times are retained.
Legacy 2D without timestamps requires explicit positive delta_t and preserves
within-particle row order. An existing timestamp column rejects delta_t.

mapping_io.infer_file orchestrates reading and the independently callable
model; save_results handles figures and numerical output after inference.
gpdiffusion_cli.py supplies one thin Typer command with the plan's enums,
column overrides and defaults. Float32 is rejected as unvalidated. A GPU request
never falls back to CPU. main.py invokes that same CLI from a checkout.
Detailed numerical progress is saved to sampling.log, outside the terminal flow.

PyArrow26.0.0. Numerical dependencies and CuPy versions remain unchanged.
